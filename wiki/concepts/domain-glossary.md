# Domain glossary (admin desk)

This app is a thin client over **travelhues-api** admin routes. Prefer the API wiki for entity definitions.

| Term | In this repo |
|------|----------------|
| **Story desk** | UI for CRUD on stories/spots/itineraries via admin API |
| **Settings** | Platform defaults the app reads from `GET /settings` |
| **ADMIN_TOKEN** | Shared secret; sent as Bearer token to API |

See [ecosystem.md](ecosystem.md) for ports and env vars.
